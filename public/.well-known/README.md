# `.well-known/` — Universal Links + App Links

These two files **must be served from `https://app.neuralconnexions.com/.well-known/...`** with `Content-Type: application/json` and *no* authentication. The native bundle's entitlements pin to that exact host.

## Files

| File | Purpose | Replace-before-ship value |
| --- | --- | --- |
| `apple-app-site-association` | iOS Universal Links | `TEAMID` → your Apple Developer Team ID (10-char alphanumeric, found in App Store Connect → Membership) |
| `assetlinks.json` | Android App Links | Both SHA-256 fingerprints (see below) |

## Hosting

Per spec D5 §G3 (resolved): host on Cloudflare Pages.

```bash
# One-time, on Sneha's local Mac:
# 1. Create a tiny "well-known-only" Pages project
mkdir -p ../nc-well-known/.well-known
cp public/.well-known/apple-app-site-association ../nc-well-known/.well-known/
cp public/.well-known/assetlinks.json            ../nc-well-known/.well-known/
cd ../nc-well-known
npx wrangler pages deploy . --project-name nc-well-known
# 2. In Cloudflare dashboard → Pages → nc-well-known → Custom domains
#    Add `app.neuralconnexions.com`. DNS is automatic if the domain is on Cloudflare.
# 3. Verify:
curl -I https://app.neuralconnexions.com/.well-known/apple-app-site-association
#    Expected: 200 OK, Content-Type: application/json (Pages does this automatically
#    for files without an extension as of 2024)
```

## Getting the Android SHA-256 fingerprints

```bash
# Debug keystore (auto-generated by Android Studio on first build):
keytool -list -v -keystore ~/.android/debug.keystore \
  -alias androiddebugkey -storepass android -keypass android \
  | grep "SHA256:"

# Release keystore — only available after Sneha generates it AND uploads to
# Google Play Console. Play Console then shows the *upload* fingerprint AND
# the *signing* fingerprint (Google re-signs); list BOTH.
# Play Console → Setup → App integrity → App signing key certificate
```

## Why this is its own subdomain

Hosting `.well-known/` on the marketing apex couples the iOS/Android entitlements to whatever else lives there. Splitting to `app.neuralconnexions.com` means: marketing can break, the apex can change CDN, and Universal Links keep working as long as this Pages project is up.
